# Aprendizaje controlado

## Objetivo

Guardar correcciones humanas, propuestas de aprendizaje y casos resueltos como una capa de mejora controlada, sin mezclar eso con la validacion determinista ni con los datos operativos del pedido.

## Criterios operativos

- Las propuestas de aprendizaje son revisables.
- Las correcciones humanas tienen trazabilidad de autor y revision.
- El aprendizaje sugiere, pero no sustituye la validacion de negocio.
- Las decisiones finales siguen dependiendo de la aplicacion y del humano.
